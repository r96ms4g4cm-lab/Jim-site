JIM — AI-CONNECTED PHONE VERSION

This version can use either:
1. Local demo brain: free, no key, scripted replies.
2. OpenRouter free-model router: real AI replies, requires an OpenRouter API key and internet.
3. Custom backend: for a compatible endpoint you already operate.

USE THE REAL AI MODE
1. Open Jim in Safari.
2. Tap Setup.
3. Set Brain mode to “Real AI via OpenRouter free-model router”.
4. Paste your OpenRouter API key into the API key field.
5. Close Setup and chat normally.

Important:
- The OpenRouter model route is named openrouter/free and selects an available free model. Availability and limits can change; free access is not unlimited. The published free plan currently lists 50 requests/day.
- Check the provider's terms and age requirements. If you are not eligible to make an account, ask a parent/guardian to help; do not misstate your age.
- The API key is not saved in local storage or written into this HTML file. It stays in the page's memory while the page is open. Clear it before leaving, and do not put it into the source code.
- Messages and any images you send in real-AI mode are sent to the provider for processing. Avoid sending sensitive personal information.
- This is a personal test build. A public app should use a secure backend that protects API keys and controls abuse/usage.
- Nuke Chat clears visible messages and Jim's in-memory conversation context. Closing/reloading the page also clears the in-memory key and context.

PUBLISH FREE WITH GITHUB PAGES (phone only)
1. Save/extract this ZIP in the Files app.
2. In Safari, sign in to GitHub and create a public repository named jim-site.
3. Upload index.html from this ZIP to the repository root and commit it.
4. Open Settings > Pages.
5. Choose Deploy from a branch, branch main, folder /(root), then Save.
6. Wait for the Pages URL and open it in Safari.
7. In Jim's Setup, choose the OpenRouter mode and enter your own API key for that session.

The site hosting is free; the AI provider is separate and has its own terms, quotas, and availability.
